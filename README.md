# 🧮 Calculadora Web

Uma calculadora simples, moderna e responsiva desenvolvida com **HTML5, CSS3 e JavaScript puro**. 

O projeto foi construído sem dependências externas, oferecendo uma interface limpa com tema escuro e suporte a operações matemáticas básicas.

---

## 🚀 Funcionalidades

- ➕ **Operações Básicas**: Adição, subtração, multiplicação e divisão.
- ⌫ **Apagar e Limpar**: Botões para apagar o último caractere ou reiniciar o visor.
- 📱 **Layout Responsivo**: Interface adaptada para ecrãs de telemóvel e computador.
- 🎨 **Tema Dark Moderno**: Design limpo e agradável visualmente.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação semântica da calculadora.
- **CSS3**: Estilização com Flexbox, Grid e variáveis visuais.
- **JavaScript (ES6)**: Lógica de cálculo e manipulação do visor.
